Button variants

Text buttons

Default uses the instrument token. Blue is the accent/action variant. Green, amber, and red stay semantic. Outlined keeps a chamfered border, while ghost removes the border.

Icon buttons

Icon-only buttons use the same six-point chamfer shape and color hierarchy as text buttons.
